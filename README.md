# SevaPath

**Find the support you’re entitled to.**

SevaPath is a civic-tech website that helps people explore government benefits and understand the steps involved in applying. It guides users from discovering possible support to organizing application documents and tracking their progress.

**Live website:** [https://aishwaryapenmetsa.github.io/seva-path/](https://aishwaryapenmetsa.github.io/seva-path/)

## Features

- Explore benefits and search the scheme directory
- Answer a questionnaire to find potentially relevant support
- View guidance, document checklists, and form explanations
- Track application progress
- Use the website in English or Telugu

## Built with

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Run locally

You’ll need Node.js and npm installed.

```bash
npm install
npm run dev
```

Open the local address shown in the terminal to view the site.

## Build for production

```bash
npm run build
npm run preview
```

## Deployment

The site is hosted on GitHub Pages. A GitHub Actions workflow builds and deploys the project when changes are pushed to the `main` branch.

## Disclaimer

SevaPath is an informational project and is not an official government website. Benefit details and eligibility can change; verify requirements with the relevant official department before applying.
