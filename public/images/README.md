# SevaPath Images Directory

Place real community, citizen, and campus photos in this folder.

## Guidelines
- Do NOT use hotlinked image URLs from external websites or random stock sites.
- Store static assets locally here so the application is self-contained and functions reliably offline and on GitHub Pages.
- Format recommendations: Modern optimized `.webp` or `.svg` format with descriptive filenames (e.g., `student-hero.webp`, `farmer-support.webp`).
- Always specify meaningful, descriptive `alt` text on any `<img>` tag where these images are rendered to ensure WCAG AA accessibility compliance.
